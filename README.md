# LSH-2026_Gamedev-Developer-TestTask
Тестовое задание для ЛШ-2026 для мастерской GameDev по направлению разработчик

**Реализованные механики**

Архитектура:
Единая точка входа сначала в игру с загрузкой основных систем и сервисов, затем в конкретную сцену. 
Для прокидывания явных зависимостей используется ServiceLocator.
Все апдейты вынесены в единый апдейт через UpdateManger в GameLoop.
Реализация объектов на сцене и их логики преимущественно сделана с помощью MVC паттерна.
Механики поведения врагов вынесены в отдельные классы, что позволило бы в теории удобно собирать новых врагов из компонентов(но не успел)
EventBus, благодаря которому можно удобно подписываться на глобальные события из разных классов.

Глобальные механики:
Камера двигается за игроком в одну сторону, проход назад заблокирован, как в оригинальном Марио.
Очки накапливаются за подбор монет, убийство врагов и оставшееся время.
Монеты не сбрасываются при обычной смерти, но сбрасываются при рестарте.
Таймер работает, и сбрасывается при рестарте или смерти, но забыл сделать смерть по истечению времени.
Смерть от падения.
Победная заставка при окончании уровня и рестарт игры.

Механики персонажа:
Прыжок с проверкой земли.
Основа для двойного прыжка, но не успел сделать бонус, который бы это давал.
Убийство врагов приземлением на голову.

Механики врагов:
Патрулирование территории от стенки к стенке.
Проверка земли и падение.
Смерть.
